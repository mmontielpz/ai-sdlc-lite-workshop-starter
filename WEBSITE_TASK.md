# Challenge: responsive landing page

Using the starter in `website/` and its included placeholder images (`website/src/assets/placeholder/`), build **one responsive landing page**. You choose the theme, colors and content; use fictional data only.

**Scope:** one page; responsive layout; existing components and assets. No backend, authentication, database, deployment, new framework or new dependencies. The starter is React + Vite + Tailwind; keep it that way.

**Where to edit:** `website/src/content/` (text, agenda, speakers, sponsors, FAQ), `website/src/components/`, `website/src/index.css` (color variables), `website/tailwind.config.js`, `website/index.html`. Do not edit `package.json` or `package-lock.json`.
