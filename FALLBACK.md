# Fallback: no Copilot, no inference, or no budget

**Option 1: do it yourself (10 minutes).** Follow [WEBSITE_TASK.md](WEBSITE_TASK.md) by hand in `website/`, running `npm run lint && npm run build` after each step; or the optional Python [TASK.md](TASK.md) in `expenses.py`, running `./check.sh` after each step until it passes. You still practice bounding scope and verifying independently.

**Option 2: read-only agent.** Open `copilot`, ask it to explain `expenses.py` and propose a plan only; decline all edit and shell prompts.
