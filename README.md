# AI-SDLC Lite workshop starter kit

A self-contained workshop kit. The primary exercise is a responsive landing page in `website/` (see [START_HERE.md](START_HERE.md)); an optional Python expense-report CLI exercise also practices a bounded, verified agent task with GitHub Copilot CLI and [AI-SDLC Lite](https://github.com/mmontielpz/ai-sdlc-lite) (experimental). Start with [START_HERE.md](START_HERE.md). Standard library only; no paid services.
